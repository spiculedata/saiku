Three surfaces. One cube. Real requests.

Every widget on this page hits a live Saiku instance at demo.saiku.bi against the bundled FoodMart cube. Nothing is stubbed. If it renders here, it works.

Three sections showcase Saiku's developer surfaces — <saiku-embed> web component, the typed AI Query REST API, and the schema-per-cube GraphQL API.

Some endpoints require CORS-friendly access from this origin. If a section reports a network error, the demo instance may be temporarily locked down or rate-limited. Refresh, or fall back to curl against demo.saiku.bi directly.

1. <saiku-embed> web component

One custom element, three modes — table, matrix, chart. Same tag works in React, Vue, Svelte, or vanilla HTML. Public-grant demo instance, no token needed.

Render =table
Render =chart (bar)
Render =matrix — hierarchical cellset (new in this branch)
